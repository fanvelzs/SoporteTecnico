# Soporte Técnico

Aplicación de escritorio desarrollada con JavaFX para registrar clientes y crear solicitudes de servicio asociadas.

## Funcionalidades

- Menú principal con navegación entre pantallas.
- Registro y validación de clientes.
- Selección de documento de identificación y directorio del cliente.
- Creación y validación de solicitudes de servicio.
- Selección de prioridad, archivo adjunto y carpeta de evidencias.
- Asociación de cada solicitud con un cliente registrado.

## Tecnologías

- Java 21
- JavaFX 21
- FXML
- Maven

## Ejecución

En Windows:

```powershell
.\mvnw.cmd javafx:run
```

En Linux o macOS:

```bash
./mvnw javafx:run
```

Los datos se almacenan en memoria durante la ejecución de la aplicación.
